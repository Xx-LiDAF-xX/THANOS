# Code of conduct

Participants should be respectful, patient and constructive. Discuss evidence and code, welcome different levels of experience and accept corrections. Harassment, discrimination, threats, personal attacks, doxxing and sharing private information without consent are not acceptable.

Maintainers may remove offending content, request changes or restrict participation when needed to protect contributors. Apply rules consistently and allow participants to explain misunderstandings privately.

Report concerns through a private GitHub contact method made available by the repository owner. If no private channel is available, request one without publishing personal details. This project does not promise a reporting address that has not been configured.
