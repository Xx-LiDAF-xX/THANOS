# Core

Dependency-free models, interfaces, evidence orchestration, diagnosis, relationship policies and knowledge semantics. ResearchModels/ResearchContracts add separate Phase 2 contracts; ResearchService composes evidence, binary inspection, diagnosis and knowledge. DiagnosisEngine separates observations/hypotheses and FamilyRelationshipEngine uses code/provenanced hash bindings. KnowledgeValidation checks semantic constraints without a storage dependency. Use ServiceFactory.CreateResearchService().ResearchAsync(game, kyty, log) through infrastructure composition. Research/schema tests cover this subsystem; see docs/PHASE2.md for API/wire semantics.
