# Infrastructure

BCL platform adapters, streaming hashes, bounded ELF inspection/address mapping/binary differences, log parsing, conservative Kyty detection, bounded knowledge JSON, application logs and SQLite. ServiceFactory composes both basic evidence and Phase 2 research. Storage/schema-v1.sql and schema-v2.sql are additive embedded migrations; SqliteKnowledgeStore implements IResearchKnowledgeStore with snapshots and transactional knowledge import/export. Binary/knowledge/storage tests use synthetic files and temporary databases. See docs/PHASE2.md for API semantics and limits.
